SAS Array Counting Guide

How to use arrays and loops in SAS to count conditional values

October 24, 2024. Filed under SAS Programming.

Overview

Introduction

Schools are assigned annual special education determination levels (DL):

  • DL 1: Meets Requirements
  • DL 2: Needs Assistance
  • DL 3: Needs Intervention
  • DL 4: Needs Substantial Intervention

Data Analysis Problem

We need to count variables in a SAS dataset that have a specific determination level value (in this case, 4). This counting helps with:

  • Data summarization
  • Tracking condition occurrences
  • Reporting and analysis according to OSEP QA 23-01

Solution Approach

The solution uses two key SAS programming elements: an array to group related variables, and a do loop to automatically check each variable. Instead of manual checking, this approach examines each variable in the array, counts occurrences of the value 4, and stores the final count in a new variable (TOTAL_NSI_CNT).

Understanding the Array and Its Components

1. Initializing a Variable

Before starting the loop, we initialize a variable that will hold the count of how many variables meet the condition. Initialization means setting a starting value. TOTAL_NSI_CNT starts at 0 because nothing has been counted yet, and this ensures the counter starts fresh for each row of data.

TOTAL_NSI_CNT = 0;

2. Defining an Array

Arrays group multiple variables together so they can be treated as a single entity. The same logic then applies to every variable without repetitive code. Here, the array dv_vars contains seven variables (DL_18 through DL_24).

array dv_vars[7] DL_18 DL_19 DL_20 DL_21 DL_22 DL_23 DL_24;

3. Using a Do Loop to Process Each Element

A do loop repeats a set of instructions until a condition is met. Here it goes through each variable in the array and checks whether it equals 4.

do i = 1 to dim(dv_vars);
  • i is a loop counter that tracks which element of the array is being processed.
  • dim(dv_vars) returns the number of elements in the array (7 in this case).
  • The loop starts at 1 and runs through the last element.

4. Checking the Condition

Inside the loop, the code checks whether each element equals 4. If it does, the counter goes up by 1. If the counter ends at 3, three of the seven variables had a value of 4.

if dv_vars[i] = 4 then TOTAL_NSI_CNT + 1;

5. Dropping the Loop Index Variable

Once the loop finishes, the index variable i is no longer needed, so it is dropped from the dataset.

drop i;

SAS Code Full Example

TOTAL_NSI_CNT = 0;
array dv_vars[7] DL_18 DL_19 DL_20 DL_21 DL_22 DL_23 DL_24;
do i = 1 to dim(dv_vars);
  if dv_vars[i] = 4 then TOTAL_NSI_CNT + 1;
end;
drop i;

Key Concepts Recap

Initialize a Variable
Setting a starting value before using it (TOTAL_NSI_CNT = 0).
Array
A collection of variables treated as a group (dv_vars).
Do Loop
Repeats a set of instructions a specified number of times.
i
The loop counter; tracks the current position in the array.
dim()
Returns the number of elements in the array.
Element
Each individual variable inside an array.
Incrementing the Counter
Adding 1 to a counter each time a condition is met.
Drop
Removes unneeded variables (like i) from the final dataset.

Conclusion

Arrays and loops together let SAS count variables that meet a condition. The array groups the variables so the same logic applies to all of them at once, and the loop checks each one and updates the counter. This technique is useful in reporting and analysis wherever values need to be summarized across many data points.
